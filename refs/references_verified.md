## NBSR software version: RESOLVED 2026-10-19

The NBSR paper was verified above, but the *software* had no recoverable version. It is now
identified exactly.

**Cite as:** NBSR, github.com/junseonghwan/nbsr, commit
**`dc3e6adcbe1f6a1706cc39c204fe317f0a1f4090`** (23 March 2026). The repository has no release
tags, so a commit hash is the only available identifier.

**How it was established.** The installed package carries no `__version__` and no
installation metadata beyond `direct_url.json`, which records a plain-directory install from a
temporary folder that no longer exists, so no commit was ever recorded. The upstream
repository was cloned and all 154 commits were scanned for one whose `nbsr/*.py` files match
the installed copy exactly, comparing file names and a combined SHA-256 over sorted filenames
and contents. Exactly one commit matches, with the installed fingerprint being
`0825f19306fbd6917ef9103501418c8d499c0f344459012376a407a08920df1b` across 13 source files.

**Two things worth knowing about that commit.**

Its subject is *"Fixed the error with std error calculation for log RAR."* NBSR is one of the
equivalence-testing comparators in §2.10, where the standard error is precisely what the
analysis consumes, so it matters that the version used is the one *after* that fix rather than
before it. Worth a line in the Methods or the response to review if NBSR's intervals are
questioned.

The upstream code has moved substantially since: 47 commits later, with `nbsr/*.py`
restructured (`main.py` split into `fit.py`, `prior.py` and `inference.py`, `grbf.py`,
`multinomial_model.py`, `zinbsr.py` and `nbsr_eb.py` removed, around 2,000 lines changed each
way). **Anyone installing NBSR from HEAD today would not reproduce our NBSR results**, which
is the argument for citing the commit rather than the repository.

**Lesson for the environment, recorded so it does not recur:** the package was pip-installed
from a copied directory rather than from the git URL, which discarded the provenance. Install
Python dependencies from their VCS URL (`pip install git+https://...@<commit>`) so that
`direct_url.json` records the commit.

**Schuirmann is resolved and the abstract problem goes away.** The canonical citation is the
*J Pharmacokinet Biopharm* paper, which is indexed and peer-reviewed. The commonly seen *The
Pharmacologist* 29:262 is a conference abstract of the same work; cite the journal paper.

## A precision problem in our own text, found while verifying Tham

v3's Introduction says glaucoma affects "more than 70 million people worldwide [REF: Tham
2014]". Tham et al. report **64.3 million** in 2013, projected to **76.0 million** in 2020 and
**111.8 million** in 2040. So "more than 70 million" matches neither the headline estimate
nor the year it was published, and sits between two of their numbers.

**Suggested replacement, which is both accurate and stronger:** "affecting an estimated 76
million people in 2020 and projected to reach 112 million by 2040 [REF: Tham 2014]".
